## 📂 Proyectos destacados

### 🏍️ Vercy Motos — ERP para tienda de repuestos
Sistema de gestión completo para un negocio de moto-partes: facturación, pedidos, caja, cartera, inventario, clientes, proveedores y reportes.
- **Backend:** Spring Boot + MongoDB, integración con API de facturación electrónica DIAN (facturas y documento soporte)
- **Frontend:** Flutter Web con 50+ pantallas, WebSockets en tiempo real, exportación PDF/Excel e impresión
- **Deploy:** Docker en VPS + Firebase Hosting

`Java` `Spring Boot` `MongoDB` `Flutter` `Docker`

### 🍽️ Kronnos Restobar — Sistema para restaurante y bar
Backend para la operación de un restobar: pedidos, mesas y comunicación en tiempo real.
- Spring Boot 3 + MongoDB Atlas, WebSockets con broker STOMP
- Contenerizado con Docker multi-stage y publicado detrás de Nginx con HTTPS

`Java 21` `Spring Boot` `WebSockets` `Docker` `Nginx`

### ⚖️ SANE — Navegador de legalización empresarial
Plataforma que guía a emprendedores en los trámites legales de su negocio con diagnóstico de riesgo, rutas paso a paso, KPIs de avance y un asistente virtual con contexto por negocio.
- **Frontend:** Flutter (Web + Mobile) con flutter_bloc y Dio
- **Backend:** FastAPI + MongoDB Atlas, autenticación con Firebase

`Flutter` `FastAPI` `MongoDB` `Firebase`

### 🚌 enBus — Tarifa estudiantil para transporte público
App móvil para validar la tarifa estudiantil mediante códigos QR temporales.
- Flutter para Android e iOS, tokens QR con expiración en Redis, PostgreSQL y JWT

`Flutter` `PostgreSQL` `Redis` `JWT`
